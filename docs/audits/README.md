# Historical audit snapshots

The dated reports, screenshots and JSON files in this directory preserve prior
review work. They describe the code, dependency advisories and deployed services
at their capture dates; they do not establish current readiness.

For current verification use `npm run verify:market` and its exact-commit GitHub
Actions results. Production release acceptance remains in
[`../PRODUCTION_LAUNCH_CHECKLIST.md`](../PRODUCTION_LAUNCH_CHECKLIST.md).

The June audit in `../REPO_AUDIT_2026-06-25.md` and October team evidence under
`../team/evidence/` are historical as well. Consolidation retains their provenance
while reconciling the later payment, account, inventory and recovery changes.

The Assets/Review prototype and plan in the parent directory are design proposals,
not a record of an implemented navigation change. The feature overview is product
context, not a sales or launch approval.
