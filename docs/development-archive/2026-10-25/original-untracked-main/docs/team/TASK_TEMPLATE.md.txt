# Task template

- **Outcome:** user-visible or operational result.
- **Source:** Daniel's request or exact existing readiness requirement.
- **Scope / exclusions:** boundaries and owned components.
- **Acceptance criteria:** observable pass/fail conditions.
- **Owner:** one configured agent ID.
- **Dependencies:** task IDs and required base commits/contracts.
- **Verification:** relevant commands/manual scenarios; safe environment.
- **Deliverables:** task branch, commit, evidence and documentation.
- **Reviewer:** independent QA and/or lead.
- **Decision boundary:** any specific human authorization needed.

Completion note: summary; commit SHA; exact checks/outcomes; reviewer and
reviewed SHA; known limitations; merge/deploy status; follow-up task IDs.
